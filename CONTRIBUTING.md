# Contributing feedback

Useful contributions are reproducible bug reports, clear feature requests and corrections to public support documentation. Read [SUPPORT.md](SUPPORT.md) and use the appropriate Issue Form. Explain the SMP problem and benefit, rather than requesting an unrelated system or assuming a release date.

SMPConnect is proprietary and its source code is private. This repository is not an invitation to submit or redistribute plugin source, decompiled files, modified JARs or private development documents. Do not attach binaries, databases, credentials, unredacted logs or personal information. Post only material you have permission to share. Suggest documentation corrections in an issue; any later code/document license agreement must be made explicitly rather than assumed from a submission.

Be respectful, avoid duplicate reports and keep discussion on the reported problem. Potential vulnerabilities belong in the confidential channel described by [SECURITY.md](SECURITY.md), never in public contributions. Acceptance of a suggestion is not a promise to implement it or provide a particular support response time.
